A delivery link is a URL under {{ base_path }} that serves content you control - a key, a file, or a pwndrop-proxied download. Everything on this page is optional except the path; the fastest start is the Quick drop button on the Links page.

CHOOSE A KIND

  • Key - serve short text (license key, config blob) as a small page.
  • File - serve an uploaded payload at a stable URL.
  • Proxy - fetch from a pwndrop URL server-side; the source is never exposed.

CHOOSE A GATE

  • No gate - anyone with the URL gets the content.
  • Token / TOTP - the visitor presents a shared token or a timed code.
  • Submission - the agent POSTs an encrypted package (hostname, screenshots); an operator approves before release.
  • IP / User-Agent only - no credentials; the NETWORK PROFILE below decides. With operator admission on (the default), the allow-lists are optional: every visitor waits for your decision. Fields you don't need stay hidden until you pick the matching option.

WHILE HELD / ON DENY

  • Held requests can show a blank 204, the decoy, or a redirect. Denied ones return 404, the decoy, or your benevolent content.
  • The network profile (IP / UA / header contract / time window) is checked before credentials - failures look identical to a wrong token.
